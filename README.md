## 🚀 About

> **Built autonomous research agent producing cited reports from 10+ sources in <90s**

**AutoResearch Agent** is a production-ready **Agents** project built with **Python, LangChain, OpenAI, Tavily**.
Deployed on **Render** with full CI/CD pipeline.

## 🚀 Quick Start

```bash
# 1. Clone
git clone https://github.com/alam025/auto-research-agent.git
cd auto-research-agent

# 2. Install
pip install -r requirements.txt

# 3. Run
python main.py
```
